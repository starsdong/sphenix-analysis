\section{Glossary}
\label{sec:glossary}
\begin{description}\small
\item[PV] primary vertex; \emph{original}: stored \texttt{SvtxVertexMap} vertex; \emph{pair refit}: re-implemented
  pair-average vertex; \emph{KF fit}: KFParticle vertex fit. ``All'' = with all attached tracks, otherwise without the
  candidate's daughters.
\item[DIRA] cosine of the angle between the candidate momentum and the PV-to-decay-vertex direction.
\item[$L$, \Ls] decay length and its significance w.r.t.\ the PV.
\item[pointing / tight / control] DIRA $>0.995$ \& $\Ls>2$ / DIRA $>0.999$ \& $\Ls>5$ / $0.95<$\,DIRA\,$<0.98$.
\item[$S$, $C$, $P$] signal-region spectrum, control spectrum, weighted prediction (Sec.~\ref{sec:method}).
\item[$z$] window excess divided by the Poisson error of the window count.
\item[$\kappa$] momentum-scale factor, $\pt^{\rm corr}=\kappa\pt$.
\item[v1 / v2] fix-1--2 production (stock candidate set, cluster 480622) / fix-1--5 production (this note, cluster 480634).
\end{description}
