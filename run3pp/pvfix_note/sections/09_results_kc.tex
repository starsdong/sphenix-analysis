\section{Results with the momentum-scale correction}
\label{sec:resultskc}
The search of Sec.~\ref{sec:method} is repeated with the corrected mass, \Dzero{} \pt{} and momentum asymmetry
(\fpath{pvfix10pct/pvfix_d0_v2_kc.C}, generated from \fpath{pvfix_d0_v2.C} by replacing these three quantities; window,
binning and the 15\mev{} narrow-peak width unchanged). The all-\pt{} selections contain exactly the same candidates as
without the correction (\chkAllPtSame); with $\pt>1.5\gevc$ the set changes slightly because the \Dzero{} \pt{} changes
(original PV, pointing: \nsChangeHiP\%).

Without extra cuts, \zGtTwoKcNone{} of the 12 selections have $|z|>2$ (largest \zAbsMaxKcNone), \zPosKcNone{} of 12
excesses are positive, the mean $z$ is \zMeanKcNone{} and the r.m.s.\ \zRmsKcNone{} (uncorrected: \zMeanNone{} and
\zRmsNone). With both pair requirements: \zGtTwoKcBoth{} with $|z|>2$, largest \zAbsMaxKcBoth, r.m.s.\ \zRmsKcBoth. The
injected peak is still recovered at \recMinKcNone--\recMaxKcNone\% (\chkInjKcNone, \chkInjKcBoth).

The pattern over PV versions is not consistent: each version has a local excess (largest $z$ \zMaxOrigKcNone{} original,
\zMaxPairKcNone{} pair refit, \zMaxKfKcNone{} KF fit), but in different selections -- e.g.\ \Dzero{} $\pt>1.5\gevc$ pointing has $z=\zOrigHiPKcNone$ with the original PV but
\zPairHiPKcNone{} and \zKfHiPKcNone{} with the refits, although the refits select a largely overlapping sample. A real
\Dzero{} signal would be expected at least as strongly with the refits, which remove the bias against displaced decays.
