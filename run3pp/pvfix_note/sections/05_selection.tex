\subsection{Track pairs: crossings and collisions}
\label{sec:pairs}
In a DST event the tracks span hundreds of bunch crossings; the crossing match is what restricts the pairing to one
collision. Checked on one file each of two runs (\fpath{tools/pvfix/pair_crossing.C}): in run 79513 (\pcNA{} candidates)
and run 81609 (\pcNB) the two daughters have the same crossing in \pcSameA\% / \pcSameB\% of the candidates, and the PV
crossing equals it in \pcPvA\% / \pcPvB\%. The daughter crossings range from \pcXloA{} to \pcXhiA{} (5--95\%) within an
event; a crossing contains a median of \pcTrkMedA{} tracks (\pcTrkLoA--\pcTrkHiA). \pcMultiPvA\% / \pcMultiPvB\% of the
candidates come from crossings with more than one PV (pile-up or split vertices), and \pcInttA\% / \pcInttB\% have INTT
hits on both daughters (otherwise the crossing is estimated from the tracking).

Two pair requirements are studied offline (Table~\ref{tab:paircuts}, \fpath{tools/pvfix/pair_cuts_study.C}, stored PV,
both $|{\rm DCA}|>60\um$, $L<1$\,mm):
\begin{itemize}
\item \emph{INTT}: both daughters have $\geq1$ INTT hit, so the crossing comes from INTT timing.
\item \emph{same collision}: each daughter is attached to the candidate's PV or has $|\Delta z|<1$\,mm to it, with
  $\Delta z=\sqrt{{\rm DCA}^2-{\rm DCA}_{xy}^2}$ w.r.t.\ the stored PV. 1\,mm is wide compared with \Dzero{} daughter
  displacements ($\sim$100\um) and narrow compared with the cm-scale separation of collisions in one crossing.
\end{itemize}

The INTT requirement removes the same fraction of pointing and control candidates (\cutPtAllIntt\% vs \cutCtAllIntt\%
kept). The same-collision requirement keeps \cutPtAllColl\% of the pointing candidates (rounded) and \cutCtMultiColl\% of
the control candidates in multi-PV crossings. There, \cutCtMultiGt\% of the daughters not attached to the PV lie more
than 1\,mm from it (median $|\Delta z|$ \cutCtMultiDmed\,mm): pairs across collisions exist in the control sample, but
the pointing requirement already rejects them.

\choice{Both pair requirements are applied in the main results (\extraFracBoth\% of the analysis base sample kept).
The INTT requirement is kept for its cleaner crossing assignment; the same-collision requirement costs nothing.
Results without them are given for comparison.}

\subsection{Offline selection}
\paragraph{Skim} (\fpath{tools/pvfix/skim_pvfix2.C}): both daughters $\pt>0.5\gevc$, and both $|{\rm DCA}|>60\um$ and
DIRA $>0.95$ w.r.t.\ at least one PV version (the original only if \texttt{pvfix\_passOriginal}). \skimIn\,M $\to$
\skimOut\,M candidates.

\paragraph{Analysis base sample:} pair refit and KF fit both valid: \baseNone\,M candidates (\baseFracNone\% of the
skim). Then, separately for each PV version $v$ (original, pair refit, KF fit):
\begin{itemize}
\item both daughters $|{\rm DCA}_v|>60\um$, decay length $L_v<1$\,mm (prompt-like); for the original PV also
  \texttt{pvfix\_passOriginal} (the stock in-job selection), so that the original column is the stock analysis;
\item \emph{pointing}: DIRA$_v>0.995$ and $\Ls{}_v>2$; \emph{tight}: DIRA$_v>0.999$ and $\Ls{}_v>5$;
  \emph{control} (non-pointing): $0.95<{\rm DIRA}_v<0.98$;
\item \Dzero{} $\pt>1.5\gevc$, or all \pt.
\end{itemize}
The three versions select overlapping but different candidates (Table~\ref{tab:counts}); they are not independent.
