\section{Dataset, software and processing}
\label{sec:dataset}

\paragraph{Data.} sPHENIX Run-3 p+p track DSTs, production \texttt{ana581\_2026p005\_v001}, data type
\texttt{DST\_TRKR\_TRACKS}, on \fpath{/sphenix/lustre01/sphnxpro/production/run3pp/physics/}. The 10\% sample uses the
job lists of the earlier 10\% stock production (\fpath{output/prod10pct/lists/}): \nListsTen{} lists with
\nSegsTen{} DST segments, \eventsTwo\,M events, \nRunsTen{} runs from \runFirst{} to \runLast:
\begin{center}\small \runListTen \end{center}
The remaining 90\% (63{,}302 job lists, same lists as the stock 90\% production) has been processed with the same
software (cluster 480665, all jobs OK); it is not used here.

\paragraph{Software.} Release \release{} (ROOT \rootVersion), with \texttt{KFParticle\_sPHENIX} rebuilt from the
branch \texttt{d0-pvfix} of a local \texttt{coresoftware} clone (\fpath{src/coresoftware_kfp}). Table~\ref{tab:commits}
lists the commits; each one is reproduced by a patch script in \fpath{tools/pvfix/patch_fix*.py}. The installed library
(\fpath{install_pvfix_v2/}, md5 \texttt{\libMdfive\ldots}) is frozen for the production, and so is the macro
(\fpath{macro/pvfix2/Fun4All_run3pp_KFP.C}). The run-time configuration is set by environment variables in
\fpath{macro/run_kfp_pvfix2.sh} (Table~\ref{tab:config}).

\paragraph{Processing.} HTCondor on \texttt{sphnxuser01}, one job per list (\texttt{-1} events = all), D0 channel only,
\texttt{prod} cut set. A job counts as OK if its log contains \texttt{All done}; the log is then gzipped. Cluster 480634
(\fpath{output/pvfix2_10pct/}): \jobsOkTwo{} of \jobsTotalTwo{} jobs OK, \jobsFailTwo{} failed, \eventsTwo\,M events,
\sizeTwo\,GB of output. The previous production of the same lists with fixes 1--2 only (cluster 480622,
\fpath{output/pvfix10pct/}) processed the same \eventsOne\,M events and serves as the stock reference: its candidate set
is the stock one (fixes 1--2 do not change the selection). Analysis outputs are in
\fpath{output/pvfix2_10pct/analysis/full/}.

\caveat{About 1\% of the jobs ran 10--12\,h at under 20\% CPU (input reads from a few runs, 81556--81601 and
80895--80908); none failed. The slow jobs are a cluster I/O effect and do not affect the output.}
